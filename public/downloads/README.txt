Put the Windows installer here before you deploy the website:

  ROYAL-POWER-Setup.exe        (created by: npm run desktop:build, found in the "release" folder)

The "Download App" buttons on the website link to /downloads/ROYAL-POWER-Setup.exe.
If the installer is too big for your host, upload it to GitHub Releases instead and paste
that link in Admin -> Settings -> "Desktop app download link".
